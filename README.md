# CPP Module 03

## Overview

**CPP Module 03** introduces **inheritance** and explores how classes can extend and specialize the behavior of other classes.

The module uses the `ClapTrap`, `ScavTrap`, and `FragTrap` classes to demonstrate different forms of inheritance and class relationships.

## Objectives

* Implement class inheritance.
* Create derived classes from a base class.
* Override inherited behavior.
* Understand constructors and destructors in inheritance.
* Manage inherited attributes and methods.
* Explore multiple levels of inheritance.

## Skills Developed

* **C++**
* Inheritance
* Base and derived classes
* Method overriding
* Constructors and destructors
* Protected members
* Class hierarchies
* Object-oriented design
